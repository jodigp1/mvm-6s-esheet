6S Audit MVM

Aplikasi web internal untuk mendigitalisasi proses audit 6S (Sort, Set in Order, Shine, Standardize, Sustain, Safety) di lingkungan kerja — menggantikan pencatatan manual berbasis kertas dan spreadsheet.

Versi 1.0
Tanggal 6 Juni 2026
Status ✅ Production
Platform Web App (Netlify)
1
Ringkasan Produk

6S Audit MVM adalah aplikasi web internal untuk mengelola dan menjalankan audit 6S di lingkungan kerja manufaktur. Aplikasi ini dibangun untuk menggantikan proses audit manual berbasis kertas, mempercepat pengisian skor, menyimpan histori audit secara terpusat di cloud, dan menyediakan analitik berbasis data.

Target pengguna: Tim PIC 6S dan auditor internal perusahaan.

2
Tujuan Produk
  • Digitalisasi proses audit 6S yang sebelumnya manual/spreadsheet
  • Memudahkan pencatatan skor dan catatan temuan per auditee secara real-time
  • Menyimpan histori audit secara terpusat di cloud (Supabase)
  • Menyediakan laporan dan analitik untuk monitoring tren kualitas 6S per lokasi/periode
  • Menghasilkan dokumen audit (PDF) yang dapat diarsipkan beserta tanda tangan digital
  • Sistem scalable — berfungsi tanpa batas tahun, lokasi dapat dikonfigurasi

Logika Penilaian

Skala Skor (0–4)

0
Sangat Buruk
1
Buruk
2
Cukup
3
Baik
4
Sangat Baik

Formula Perhitungan

Total Skor = Σ (nilai_item × bobot_item)
Skor Maks = Σ (4 × bobot_item)
Persentase = (Total Skor / Skor Maks) × 100

Kategori Hasil

Excellent
≥ 85%
Badge: EX
Standard
60 – 84%
Badge: SD
Need Improvement
< 60%
Badge: NI
⚠️
Catatan Wajib
Skor ≤ 2 mewajibkan pengisian field catatan/temuan. Textarea tampil otomatis dengan visual warning.

Fitur & Halaman

6.1 Login /login

  • Form input password tunggal (internal shared password)
  • Validasi di server-side; token disimpan di cookie HTTP-only
  • Redirect ke / setelah berhasil login

6.2 Setup Sesi / (Home)

Fungsi: Membuat atau melanjutkan sesi audit

Alur 3 Langkah:

  • Langkah 1 — Pilih Lokasi: Visual card per lokasi, icon dinamis, highlight saat aktif
  • Langkah 2 — Tanggal Audit: Custom date picker (navigasi bulan, quick-pick Hari ini / Kemarin)
  • Langkah 3 — PIC Auditor: Searchable dropdown; jumlah PIC mengikuti konfigurasi lokasi (1 atau 2)

Resume Sesi Draft:

  • Sesi berstatus draft tampil sebagai card peringatan kuning
  • Tombol Resume melanjutkan ke /audit dari posisi auditee yang belum diisi

Validasi: Lokasi, tanggal, dan auditor 1 wajib diisi. Auditor 2 wajib jika jumlah_pic ≥ 2.

6.3 Audit /audit

Fungsi: Mengisi skor dan catatan untuk setiap auditee
  • Header sticky: nama auditee aktif, lokasi, PIC, timer real-time (HH:MM:SS)
  • Progress bar + dot indicator (abu=belum, hijau=selesai, kuning=skip, biru=aktif)
  • Modal daftar auditee untuk navigasi langsung ke auditee mana saja
  • Referensi skor (label + warna) tampil di atas checklist
  • Setiap checklist item: tombol skor 0–4 + field catatan
  • Skor ≤ 2: textarea catatan wajib dengan visual warning kuning
  • Skor ≥ 3: input teks catatan opsional
  • Modal Skip: pilih alasan (Cuti / Sakit / Dinas luar / Lainnya) + keterangan bebas
  • Setelah auditee terakhir: simpan waktu → redirect ke /review
  • Auto-resume: data yang tersimpan di Supabase di-load otomatis

6.4 Review /review

Fungsi: Melihat ringkasan hasil audit + export PDF
  • Header info sesi: lokasi, tanggal, PIC, durasi audit
  • Tabel rekap: baris per auditee × kolom per checklist item
  • Setiap sel skor berwarna sesuai score_config
  • Sub-row catatan temuan untuk item dengan skor rendah (muncul di bawah baris auditee)
  • Kolom total skor, persentase, dan badge kategori (EX/SD/NI)
  • Baris skip ditandai khusus dengan alasan
  • Kartu tanda tangan digital (Dancing Script font + nama tercetak tebal)
  • Export PDF via window.print() dengan @media print CSS khusus (A4 landscape)

6.5 History /history

Fungsi: Melihat semua sesi audit yang sudah selesai

Filter: Tahun (dinamis dari Supabase) · Bulan · Kategori · Urutan

  • List sesi: tanggal, lokasi, PIC, jumlah auditee, avg score, badge kategori dominan
  • Klik sesi → modal detail lengkap (tabel + sub-row catatan + tanda tangan)
  • Export PDF dari modal: full HTML di new window + auto-print (termasuk baris catatan)

9
Batasan & Out of Scope (v1.0)
  • Tidak ada multi-tenant / multi-perusahaan
  • Tidak ada notifikasi email atau push notification
  • Tidak ada peran user berbeda (semua user setara)
  • Tidak ada versioning checklist (perubahan langsung overwrite)
  • Export hanya PDF dan PNG/CSV (tidak ada Excel/XLSX)
  • Tidak ada mode offline
